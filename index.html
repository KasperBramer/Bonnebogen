Siden kunne ikke starte

Åbn browserens konsol (F12 → Console) og se hvilken fil der fejler. De typiske årsager:

  • 404 på app.js eller style.css — filerne ligger ikke der hvor index.html leder. Alle filer skal ligge samme sted.
  • Fejl i config.js — Project URL og anon-nøgle er ikke sat rigtigt ind.
  • CORS eller modul-fejl — du har åbnet filen med file://. Brug GitHub Pages eller python3 -m http.server 8000.
